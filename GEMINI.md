
Это full-stack веб-приложение для бойцовского клуба "JAGUAR FIGHT CLUB".

**Назначение:**

*   **Клиенты:** отслеживать свой прогресс, просматривать расписание тренировок, взаимодействовать с тренерами и другими участниками клуба.
*   **Тренеры:** управлять своими клиентами, назначать тренировки, отслеживать их прогресс.
*   **Администраторы:** управлять пользователями, контентом и другими аспектами приложения.

**Технологический стек:**

*   **Фронтенд:** React, Vite, Tailwind CSS, Radix UI (для готовых компонентов).
*   **Бэкенд:** Node.js, Express, SQLite (судя по зависимостям).
*   **Развертывание:** Docker, Nginx.

**Структура проекта:**

*   `backend/`: Содержит бэкенд-код на Node.js/Express.
    *   `src/`: Основной исходный код бэкенда.
        *   `middleware/`: Промежуточные обработчики Express (аутентификация, валидация).
        *   `models/`: Модели данных (взаимодействие с базой данных).
        *   `routes/`: Маршруты API (эндпоинты).
        *   `telegram/`: Интеграция с Telegram ботом.
        *   `utils/`: Вспомогательные функции.
*   `src/`: Содержит фронтенд-код на React.
    *   `components/`: Переиспользуемые React-компоненты.
        *   `ui/`: Базовые UI-компоненты (кнопки, инпуты и т.д.), вероятно, на основе Radix UI.
    *   `contexts/`: Контексты React (например, для аутентификации).
    *   `hooks/`: Пользовательские хуки React.
    *   `lib/`: Библиотечные функции.
    *   `services/`: Сервисы для взаимодействия с API.
    *   `utils/`: Вспомогательные функции.
*   `docker/`: Файлы конфигурации Docker.
*   `nginx/`: Файлы конфигурации Nginx.
*   `scripts/`: Скрипты для сборки, развертывания и т.д.

**Ключевые файлы:**

*   `package.json`: Определяет зависимости и скрипты для фронтенда и бэкенда.
*   `vite.config.js`: Конфигурация сборщика Vite для фронтенда.
*   `docker-compose.yml`: Определяет сервисы для Docker.
*   `nginx/nginx.conf`: Конфигурация веб-сервера Nginx.
*   `backend/server.js`: Точка входа для бэкенд-приложения.
*   `src/main.jsx`: Точка входа для фронтенд-приложения React.
